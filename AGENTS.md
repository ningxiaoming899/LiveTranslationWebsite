## Project Guidance

- For any UI, landing page, or frontend work in this project, use the root DESIGN.md as the primary visual specification.
- The full downloaded template library is available under vendor/awesome-design-md/ if you want to switch to a different design language later.
- If a user asks for a different visual style, replace the root DESIGN.md with the matching file from vendor/awesome-design-md/design-md/<site>/DESIGN.md before implementing the UI.
